# Claude Widget

Claude Code 세션 상태를 데스크톱 캐릭터로 보여주는 위젯. 윈도우에서 검증했고 맥은 실험적이다.

맥 전용인 Masko Code / Clabotch / Varie Claude Avatar 같은 도구를 윈도우에서 쓰려고 만들었다.
캐릭터가 화면 위에 떠 있다가, Claude Code 가 도구를 실행하거나 응답을 마치면 말풍선으로 알려준다.
캐릭터를 클릭하면 아래로 사용량 패널이 펴진다.

![구성](docs/preview.png)

## 필요한 것

- Python 3.9 이상
- 윈도우 (검증됨) 또는 macOS (코드는 들어 있으나 실기 검증 전). 리눅스는 지원하지 않는다
- Pillow (`pip install pillow`)
- Claude Code (훅 설정 가능해야 함)

## 설치

VS Code 에서 이 저장소를 열고 Claude Code 에게 `INSTALL.md 대로 설치해줘` 라고 하면
파이썬 확인부터 훅 등록까지 알아서 처리한다.
개발 지식 없는 사람에게 전달할 때는 [GUIDE.md](GUIDE.md) 를 보내면 된다.

직접 하려면 아래 순서를 따른다.

1. 이 폴더를 옮기지 않을 자리에 둔다. 설치 후 경로가 설정에 저장되므로 나중에 옮기면 훅이 끊어진다.

2. Pillow 를 설치한다.

   ```bash
   pip install pillow
   ```

3. `~/.claude/settings.json` 의 `hooks` 에 아래 3개 이벤트를 추가한다.
   `<PYTHON>` 은 `where python` 으로 확인한 경로, `<WIDGET>` 은 이 폴더 경로.
   기존 설정을 덮어쓰지 말고 `hooks` 안에 병합한다.

   ```json
   {
     "hooks": {
       "PreToolUse": [
         { "matcher": "", "hooks": [{ "type": "command", "command": "\"<PYTHON>\" \"<WIDGET>\\hook.py\"" }] }
       ],
       "Notification": [
         { "matcher": "", "hooks": [{ "type": "command", "command": "\"<PYTHON>\" \"<WIDGET>\\hook.py\"" }] }
       ],
       "Stop": [
         { "matcher": "", "hooks": [{ "type": "command", "command": "\"<PYTHON>\" \"<WIDGET>\\hook.py\"" }] }
       ]
     }
   }
   ```

   **윈도우 경로의 역슬래시는 JSON 안에서 `\\` 로 이스케이프한다.** `<WIDGET>` 을
   `C:\Users\name\claude-widget` 처럼 그대로 치환하면 `\U` 나 `\n` 이 잘못된 이스케이프로 읽혀
   `settings.json` 전체가 파싱에 실패한다. 그러면 훅만 죽는 게 아니라 같은 파일에 들어 있는
   `permissions` 와 MCP 설정까지 통째로 무시된다. 위 예시의 `\\hook.py` 처럼
   `C:\\Users\\name\\claude-widget\\hook.py` 로 겹쳐 쓰고, 저장한 뒤 JSON 파싱으로 유효성을 확인한다.
   맥 경로는 `/` 라서 이스케이프가 필요 없다.

4. Claude Code 를 다시 시작한다. 첫 훅이 울리면 위젯이 알아서 뜬다.

바로 띄워보고 싶으면 `pythonw widget.py` 로 직접 실행해도 된다.

## 사용법

| 동작 | 방법 |
|---|---|
| 위치 이동 | 캐릭터를 드래그 |
| 사용량 패널 펴기/접기 | 캐릭터를 클릭 |
| 이미지 변경 | 우클릭 → 이미지 변경 (PNG, JPG, GIF, WebP) |
| 크기 변경 | 우클릭 → 크기 (96 / 128 / 180 / 240) |
| 항상 위 끄기 | 우클릭 → 항상 위 끄기 |
| 위치 초기화 | 우클릭 → 위치 초기화 (화면 밖으로 나갔을 때) |
| 말풍선 닫기 | 말풍선을 클릭 |
| 잠시 끄기 | 우클릭 → 끄기 (1시간, 오늘 하루, 다시 켤 때까지) |
| 이번만 닫기 | 우클릭 → 이번만 닫기 (다음 도구 호출에 다시 뜬다) |

캐릭터 이미지는 **배경이 투명한 PNG 또는 GIF** 를 권장한다. 움직이는 GIF 도 그대로 재생된다.
바꾼 이미지는 `config.json` 에 경로로만 저장되므로 원본 파일을 지우면 기본 캐릭터로 돌아온다.

## 말풍선

말풍선 위에는 세션이 돌고 있는 **프로젝트 폴더명**이 붙는다.
하위 폴더에서 작업하더라도 `.git`, `.claude`, `CLAUDE.md` 중 하나가 있는 상위 폴더까지 거슬러 올라가므로
`myproject/src` 에서 작업해도 `폴더 myproject` 로 표시된다.

| 상태 | 표시 | 언제 |
|---|---|---|
| 도구 실행 중 | Claude 가 방금 한 말 + `Bash` 실행중 | 도구를 실행할 때 |
| 입력 대기 | 알림 문구 | 권한 승인이나 입력을 기다릴 때 |
| 응답 완료 | 마지막 응답 요약 | 답변이 끝났을 때 (8초간 표시) |

여러 폴더에서 Claude Code 를 동시에 돌리면 **폴더마다 말풍선이 하나씩** 생겨 위로 쌓인다.
가장 최근 것이 캐릭터 바로 위에 꼬리를 달고 붙고, 한 번에 최대 3개까지만 보인다.
화면 위쪽 공간이 모자라면 넘치는 것은 그리지 않는다.

말풍선 본문은 `MAX_BUBBLE_BODY_H` (기본 150px) 를 넘기면 잘리고 뒤에 `…` 가 붙는다.
본문에 상한이 있고 머리글과 여백은 고정이라 전체 높이는 210px 안쪽에 머문다.
지금 스냅샷 픽스처에서 가장 높은 것이 꼬리를 포함해 195px 다.

글자 수나 줄 수로는 높이가 안 잡힌다. 한글은 한 줄에 21자, 영문은 45자가 들어가므로
같은 60자라도 한글이면 3줄이 되고, 줄 수로 세면 빈 줄과 제목이 더하는 여백이 빠진다.
그래서 그려진 높이를 직접 재서 자른다.

세션이 인터럽트나 강제 종료로 끝나면 Stop 훅이 오지 않으므로 상태별로 표시 만료를 둔다.
도구 실행 표시는 90초, "작업중..." 은 180초, 입력 대기는 10분이다.
30분간 갱신이 없는 세션은 상태 파일 자체가 삭제된다. 파일에 응답 일부가 들어 있기 때문이다.

## 사용량 패널

`~/.claude/.credentials.json` 의 OAuth 토큰으로 `api.anthropic.com/api/oauth/usage` 를 조회해
5시간 세션과 주간 전체, 모델별 사용률을 막대로 보여준다. 패널이 열려 있는 동안 5분마다 자동 갱신한다.
맥은 이 파일이 없으면 로그인 키체인(`Claude Code-credentials`)에서 같은 JSON 을 읽는다.

토큰은 조회 시점에만 읽고 어디에도 저장하거나 기록하지 않는다. 리다이렉트는 따라가지 않는다.
파이썬 표준 `HTTPRedirectHandler` 는 Authorization 헤더를 다음 목적지로 그대로 옮기므로,
중간 프록시가 302 를 돌려주면 토큰이 의도하지 않은 호스트로 넘어간다. 그래서 302 는 따라가지 않고
`http-302` 오류로 표시하고 끝낸다.

막대 아래에는 구분선 하나를 두고 **오늘 토큰** 한 줄이 붙는다. 이 줄만은 API 가 아니라 로컬 기록에서
집계한다. `~/.claude/projects/**/*.jsonl` 의 `message.usage` 를 읽어 input, output, cache write,
cache read 네 값을 더하고, 그 아래에 모델별 내역을 한 줄로 붙인다. 칸에 안 들어가는 모델은 생략한다.

- 하루 기준은 로컬 자정이다. 기록의 `timestamp` 는 UTC 라 날짜 문자열 비교가 아니라 실제 시각으로 자른다.
- 한 응답이 content block 마다 한 줄씩 기록되므로 `message.id` 로 중복을 뺀다. 안 빼면 2배 넘게 부풀려진다.
- thinking 토큰은 output 의 부분집합이라 총합에 더하지 않는다.
- 막대는 그리지 않는다. 분모가 될 쿼터가 없어서 막대를 그리면 분모를 발명해야 한다.
- 금액으로 환산하지 않는다. 모델별 단가를 하드코딩해야 하는데 표에 없는 모델은 조용히 0원으로 들어가
  총액을 실제보다 적게 만든다. 구독 계정에서 실제로 구속되는 값은 위쪽 막대의 % 다.
- 총계 대부분은 cache read 다. 캐시 재읽기량이 그만큼 크기 때문이고, 그래서 이 숫자는 빠르게 커진다.
- 스캔은 캐시를 쓴다. 자정 이후 첫 실행은 그날 후보 파일을 전부 훑고, 그다음부터는 바뀐 파일의
  새 바이트만 읽는다. 집계는 별도 스레드에서 돌아 패널 표시를 막지 않고, 실패하면 값이 `-` 로 나온다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `widget.py` | 캐릭터 창과 메뉴, 드래그 (실행 진입점) |
| `theme.py` | 색과 폰트, 레이아웃 상수 |
| `state.py` | 설정 파일과 세션 상태 파일, 상태별 유지 시간 |
| `imaging.py` | 투명 창 표면과 이미지 준비 |
| `textlayout.py` | 마크다운을 줄 단위로 배치하고 그린다 |
| `bubbles.py` | 말풍선 창과 폴더별 쌓기 |
| `panel.py` | 사용량 패널 |
| `hook.py` | 훅이 실제로 실행하는 래퍼. 대상이 깨져도 항상 0으로 끝난다 |
| `hook_bridge.py` | 상태를 기록하고 위젯을 띄운다 |
| `usage.py` | 사용량 조회 (API) |
| `tokens.py` | 오늘 토큰 집계 (로컬 기록) |
| `markdown.py` | 말풍선용 마크다운 파서 |
| `win_layered.py` | 윈도우 픽셀별 알파 (레이어드 윈도우) |
| `single_instance.py` | 중복 실행 방지 잠금. 로컬 포트 47311 을 잡아 두고, 훅도 이걸로 생존을 확인한다 |
| `assets/default.png` | 기본 캐릭터 |
| `config.json` | 위치와 이미지, 크기 설정 (위젯 폴더에 자동 생성) |

자동 생성되는 나머지 파일은 위젯 폴더가 아니라 **사용자 전용 경로**에 있다.
윈도우는 `%LOCALAPPDATA%\claude-widget\`, 맥은 상태가 `~/.cache/claude-widget/` 와
캐시가 `~/Library/Caches/claude-widget/` 로 갈린다.

| 파일 | 역할 |
|---|---|
| `state/<폴더>-<해시>.json` | 프로젝트별 세션 상태와 마지막 응답 앞부분 (30분 후 삭제) |
| `state/_paused` | 끄기를 눌렀을 때 생기는 표식. 훅이 이걸 보고 아무 일도 하지 않는다 |
| `token-cache.json` | 토큰 집계 캐시. 훑은 파일 경로와 오프셋, 중복 제거용 응답 id |

상태 파일이 폴더 밖으로 나간 이유는 그 안에 응답 조각이 들어 있기 때문이다. 위젯 폴더 안에 두면
그 텍스트가 폴더와 함께 옮겨 다닌다. 동기화 폴더로 들어가고, 남에게 건네는 압축 파일에 실리고,
공용 PC 에서는 다른 계정도 읽는다. 대신 같은 사용자의 설치본이 두 개면 이 디렉토리를 공유한다.

파일명 뒤 8자는 프로젝트 경로의 crc32 다. 폴더명만으로는 `work/api` 와 `personal/api` 가 같은
파일을 덮어쓴다. 화면에 뜨는 이름은 JSON 안의 `folder` 값이라 이 접미사는 보이지 않는다.
예전 버전이 위젯 폴더에 만든 `state/` 폴더는 첫 실행 때 새 위치로 옮기고 지운다.

## 말풍선 마크다운

응답에 섞인 마크다운을 그대로 그린다. 지원 범위는 말풍선 크기에서 읽히는 것까지다.

| 문법 | 표시 |
|---|---|
| `**굵게**` / `__굵게__` | 굵은 글씨 |
| `*기울임*` / `_기울임_` | 굵은 글씨 (기울임체는 싣지 않았다) |
| `` `코드` `` | 회색 배경 + 붉은 글씨 |
| ` ```블록``` ` | 줄 단위 회색 배경, 들여쓰기 유지 |
| `# 제목` | 큰 굵은 글씨 |
| `- 항목` / `1. 항목` | 불릿 목록, 번호 목록 |
| `> 인용` | 왼쪽 선 + 들여쓰기 |
| `[텍스트](주소)` | 파란 글씨 (주소는 숨김) |
| `---` | 가로 구분선 |

표와 이미지는 지원하지 않고, `~~취소~~` 는 기호만 떼고 평문으로 그린다.
싣는 서체가 regular, bold, mono 세 벌이라 기울임은 굵은 글씨로 대신한다. 기호가 그대로 남는 문법은 없다.

## 구현 메모

윈도우 Tk 는 픽셀별 알파를 지원하지 않고 **하나의 색만 투명 키로 지정**할 수 있다
(`-transparentcolor`). 반투명 픽셀을 그대로 두면 키 색과 섞여 가장자리에 분홍 테두리가 생기고,
알파를 0/255 로 잘라내면 테두리는 사라지지만 둥근 모서리가 자글거린다.

그래서 윈도우에서는 Tk 의 그리기 대신 **레이어드 윈도우**(`UpdateLayeredWindow`)에
프리멀티플라이드 BGRA 표면을 직접 넘긴다. 합성은 OS 가 하므로 부드러운 가장자리가 그대로 살고,
클릭은 여전히 tkinter 로 전달되며 완전 투명한 픽셀은 클릭이 통과한다.

주의할 점 두 가지를 겪었다.

- `-transparentcolor`(`SetLayeredWindowAttributes`) 와 `UpdateLayeredWindow` 는 **배타적**이다.
  색 키를 먼저 걸면 레이어드 그리기가 조용히 실패한다. 그래서 색 키는 폴백일 때만 건다.
- 레이어드 창은 Tk 가 그리지 않으므로 Label 이 비어 있다. 이벤트는 Label 이 아니라
  **최상위 창에 바인딩**해야 한다.

레이어드 그리기가 실패하는 환경에서는 예전의 색 키 + 알파 이진화 방식으로 자동으로 떨어진다.
맥은 Tk 가 실제 알파를 지원하므로(`-transparent`) 이 우회 자체가 필요 없다.

축소할 때는 두 플랫폼 모두 투명 영역에 가장자리 색을 먼저 번지게 한다.
스트레이트 알파 PNG 는 투명 픽셀의 RGB 가 검정이라, 그대로 줄이면 검정이 테두리로 딸려온다.

사용량 막대는 로컬 기록을 보지 않는다. `~/.claude/.credentials.json` 의 토큰으로 비공개 엔드포인트를
한 번 호출할 뿐이라, 그 응답 형식이 바뀌면 패널이 먼저 깨진다. `limits` 배열을 우선 읽고 없을 때만
구식 `five_hour`, `seven_day` 필드로 떨어지게 해 두었다.

반대로 오늘 토큰 줄은 로컬 기록만 본다. 같은 값을 주는 API 가 없어서 세션 기록을 직접 세는데,
쿼터가 아니라 절대량이라 위쪽 막대와 뜻이 다르다. 둘을 한 카드에 붙여 놓은 대신 구분선으로 갈라 두었다.
